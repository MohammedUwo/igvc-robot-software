## Required e-stop USB power-loss verification

When safe to intentionally trigger the e-stop:

1. Start monitoring USB devices: `watch -n 0.5 lsusb` or repeated `lsusb -t` snapshots.
2. Start relevant ROS nodes and confirm topics are publishing.
3. Trigger ESP32 e-stop.
4. Confirm all powered-hub peripherals disappear from USB and ROS topics become stale/disconnect cleanly.
5. Reset e-stop / restore hub power.
6. Confirm devices re-enumerate with stable IDs and ROS nodes reconnect or can be restarted without manual device-name edits.
7. Record exact disappearing/reappearing devices and topic behavior in this log.
